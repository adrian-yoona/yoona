# Manrope Variable

Lokalne pliki kroju Manrope służą do tekstów, nawigacji i przycisków interfejsu YOONA. Pliki są dołączone do wtyczki; przeglądarka nie pobiera fontów z Google ani z npm.

- Pakiet źródłowy: `@fontsource-variable/manrope@5.3.0` (Fontsource; dane źródłowe Google Fonts, Manrope v20).
- Archiwum: https://registry.npmjs.org/@fontsource-variable/manrope/-/manrope-5.3.0.tgz
- Pobrano: 2026-10-16 przez `npm pack`, bez uruchamiania skryptów i bez dodawania zależności projektu.
- Integralność archiwum npm (SHA-512 / Base64): `sha512-6D5dgokHsWDDMtmXHznKa0hK229NN+1a4BLPmUCLqcO1Pw5EEhWY5RFt0AcXnVRAljFFPfRtLkJePQj6LSsV6g==`.
- SHA-1 archiwum npm: `da97b427a854b8169141364b8080a9e5f3922518`.

Oba pliki są niezmienionymi plikami WOFF2 z pakietu Fontsource. Zweryfikowano SHA-512 archiwum względem rejestru npm, sygnaturę `wOF2` i długość zadeklarowaną w nagłówku obu plików. Zmienna oś `wght` obsługuje 200–800; interfejs deklaruje i używa zakresu 400–800, styl normalny. Podzbiór `latin-ext` zapewnia polskie znaki. Nie dodano odmiany kursywy.
